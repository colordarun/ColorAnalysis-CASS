## 1. 구글 시트 — 코드 값만 수정

`consultants` 탭의 코드 열에서 접두사만 바꿉니다.

| 이전 | 변경 후 |
|---|---|
| `KA-0001` | `AD-0001` |
| `KE-0001` | `ED-0001` |
| `KC-0001` | `CS-0001` |

역할 열(Admin / Educator / Consultant)은 그대로 두시면 됩니다. 이미 영어로 바꿔 두었습니다.

`records` · `rules` 탭은 손대지 않습니다. 이미 쌓인 기록도 그대로 둡니다.

> 역할 칸을 비워 두셔도 됩니다. 비어 있으면 코드 접두사(AD/ED/CS)로 자동 판별합니다.

## 2. Apps Script — 다시 붙여넣고 새 버전 배포

1. 스프레드시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 전부 지우고, 이 저장소의 `apps-script/Code.gs` 를 다시 붙여넣기
3. 저장 (Ctrl+S)
4. 오른쪽 위 **배포 → 배포 관리**
5. 기존 배포의 **연필(수정) 아이콘** 클릭
6. **버전: 새 버전** 선택 → **배포**

**"새 배포"가 아니라 "배포 관리 → 수정 → 새 버전"** 으로 하셔야 `/exec` 주소가 그대로 유지됩니다.
새 배포를 만들면 주소가 바뀌어서 3번을 다시 해야 합니다.

### 이번에 바뀐 것

- 코드 비교가 **대소문자·하이픈·띄어쓰기를 무시**합니다
- 접두사 `AD` / `ED` / `CS` → Admin / Educator / Consultant
- 역할 칸이 비면 접두사로 자동 판별
- 코드 발급 시 같은 접두사 중 맨 뒤 숫자를 찾아 +1

## 3. index.html — API_URL 다시 넣기 ⚠

**앱을 새로 빌드했기 때문에 `API_URL` 이 다시 빈 값입니다.** 이걸 잊으면 데모 모드로 돌아갑니다.

`index.html` 위쪽에서 이 줄을 찾아,

```js
const API_URL = '';
```

전에 쓰던 주소를 그대로 다시 넣습니다.

```js
const API_URL = 'https://script.google.com/macros/s/AKfycb…/exec';
```

> 2번을 "배포 관리 → 새 버전"으로 하셨다면 주소는 전과 같습니다.
> Apps Script 편집기 → 배포 관리에서 다시 복사할 수 있습니다.
