# K-Color 컬러진단표준시스템 (CASS)

Color Analysis Standard System · 색다른컬러연구소 DARUN COLOR INSTITUTE

대면 컬러진단과 색채 교육을 한 앱에서 처리합니다. 606색 K-Color 데이터를 12유형으로 배정하고,
진단 흐름을 따라 결과 카드를 만들어 A4 PNG로 내려받거나 인쇄합니다.

---

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 본체. 606색 데이터가 안에 들어 있어 이 파일 하나로 동작합니다 |
| `assets/skintone.png` | 피부 명도 기준 이미지 |
| `data/kcolor_typed.json` | 색 데이터 원본 (참조용) |
| `apps-script/Code.gs` | 구글 시트 게이트웨이 — 코드 검증 · 기록 저장 · 결과 조회 |
| `sheet/K-Color_시트서식.xlsx` | 구글 시트로 올릴 서식 (3개 탭) |
| `tools/build.py` | 원본 엑셀에서 색 데이터를 다시 만드는 스크립트 |
| `docs/설계문서.md` | 화면 흐름 · 배정 규칙 · 검증 기록 |
| `docs/배포안내.md` | 시트 · Apps Script · GitHub Pages 설정 순서 |

---

## 빠르게 확인하기

`index.html` 을 브라우저로 열면 바로 돌아갑니다.
`API_URL` 이 비어 있으면 **데모 모드**로 동작합니다 — 코드는 접두사(KA / KE / KC)만 보고 통과시키고,
진단 기록은 저장되지 않습니다.

실제로 쓰려면 `docs/배포안내.md` 를 따라 구글 시트와 Apps Script 를 연결하세요.

## 코드 체계

| 접두사 | 역할 | 사용 범위 |
|---|---|---|
| `KA-` | **Admin** | 진단 · 교육 · 관리자 |
| `KE-` | **Educator** | 교육 |
| `KC-` | **Consultant** | 진단 |

코드 목록은 앱에 들어 있지 않습니다. 구글 시트의 `consultants` 탭에만 있고,
Apps Script 가 대신 확인합니다. 저장소가 공개되어도 코드는 노출되지 않습니다.

## 진단 흐름

```
코드 입력 → 진단자 정보 → 시즌 선택 → 세부 유형 → 팔레트 → 유형 설명 → 완료
```

- **시즌 선택** 12분할 휠. 시계 방향으로 봄(warm) → 여름(cool) → 겨울(cool) → 가을(warm)
- **팔레트** 색상 계열 · 명도 · 채도 · 톤을 교집합으로 좁힙니다. 같은 시즌의 다른 유형도 켤 수 있습니다
- **BOC** 베스트 컬러 최대 10색, 그중 ★ 하나가 베스트 오브 베스트
- **결과 카드** A4 한 장. PNG 저장 또는 인쇄(PDF 저장)

★ 를 지정하지 않으면 유형 설명 단계로 넘어가지 않습니다.

## 데이터

원본 776색 중 `K-color DB v5.xlsx` 의 Pantone 열이 `x` 인 170색을 제외한 **606색**을 씁니다.

| 항목 | 값 |
|---|---|
| 사용 색 | 606 |
| 유형에 배정된 색 | 568 |
| 웜 / 쿨 | 295 / 311 (무채색은 쿨) |

색 데이터를 다시 만들려면 `tools/build.py` 를 실행하고, 나온 JSON 을 `index.html` 의
`const DB = ...` 자리에 넣습니다.
